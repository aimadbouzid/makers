# makers.si

La bibliothèque de la communauté : des **skills Claude** prêts à installer, des **prompts**
testés, des **idées** à construire, des **PDF** utiles et des **liens** choisis.

Faite pour les gens qui se servent de l'IA au quotidien, pas pour les laboratoires.

👉 **[Ouvrir la bibliothèque](https://aimadbouzid.github.io/makers/)**

---

## Ce dépôt

C'est une **copie consultable** du site, publiée sur GitHub Pages. Elle contient les
partages, leurs fichiers et les pages d'information, sous forme de fichiers statiques.
Les tris, les filtres et la recherche se font dans le navigateur.

**On y lit tout, on n'y écrit rien** : pas de compte, pas de partage, pas de vote. La
version complète, avec les comptes et la modération, tourne sur un serveur à part.

Elle ne contient aucune donnée personnelle : ni membre, ni email, ni session.
