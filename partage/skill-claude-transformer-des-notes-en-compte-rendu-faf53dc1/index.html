# Compte rendu de réunion

## Ce que tu produis
```
# Compte rendu — [sujet] — [date]
Présents : …

## Décisions
- …

## Actions
| Action | Qui | Pour quand |
|---|---|---|

## Points ouverts
- …
```

## Les règles
- Une décision est une phrase au passé : « On garde le prix à 2 500 DA. »
- Une action a toujours un responsable et une date. S'il en manque, écris « à préciser » : n'invente pas.
- Pas de résumé de la discussion : seulement ce qui a été décidé, ce qui reste à faire, ce qui reste ouvert.
- Garde les chiffres et les noms exacts des notes.
- À la fin, propose un court message à envoyer aux participants.

Installer le skill
------------------
  Dans l’appli Claude (web, ordinateur) : Paramètres → Fonctionnalités → Skills →
  importe le dossier compressé en .zip. L’exécution de code doit être activée.
  Dans Claude Code : copie le dossier dans ~/.claude/skills/ (pour toi) ou dans
  .claude/skills/ à la racine d’un projet (pour ce projet).

Claude lit le skill tout seul quand ta demande correspond à sa description.
Relis toujours un skill avant de l’installer.
