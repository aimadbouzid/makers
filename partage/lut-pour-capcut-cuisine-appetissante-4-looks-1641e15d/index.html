Installer
---------
CapCut sur ordinateur (Windows, Mac) : sélectionne le clip → Ajuster → LUT → Importer, puis choisis le fichier .cube. L’appli mobile de CapCut n’importe pas les LUT : pour le téléphone, prends plutôt nos presets.

Conseil : règle d’abord la luminosité du clip, puis baisse l’intensité de la LUT si le rendu est trop fort.
