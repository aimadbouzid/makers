Template Notion : Liste de lecture

@makers.si 21 novembre 2026 #notion#organisation#planner

Une base « Liste de lecture » prête à importer dans Notion (et lisible dans Excel ou Google Sheets) : colonnes Titre, Auteur, Statut, Note, Terminé le, Ce que j’en retiens, quelques lignes d’exemple, et une page qui explique comment s’en servir.

contenu
Dans l’archive
--------------
  Liste de lecture.csv   la base de données
  Liste de lecture.md    la page d’accueil et le mode d’emploi
  IMPORTER.txt

Un livre par ligne. Vue « Galerie » pour les couvertures, vue « Tableau » filtrée sur Statut = À lire.

Importer dans Notion
--------------------
1. Dans Notion : Paramètres → Importer → « CSV ».
2. Choisis le fichier .csv de l'archive : il devient une base de données.
3. Importe aussi le fichier .md (Importer → « Text & Markdown ») : c'est la page
   d'accueil, avec le mode d'emploi. Glisse la base dedans.

Le CSV s'ouvre aussi dans Excel et Google Sheets.
