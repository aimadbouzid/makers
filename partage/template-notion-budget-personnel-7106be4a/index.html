Template Notion : Budget personnel

@makers.si 21 novembre 2026 #notion#organisation#planner

Une base « Budget personnel » prête à importer dans Notion (et lisible dans Excel ou Google Sheets) : colonnes Nom, Catégorie, Type, Montant, Date, quelques lignes d’exemple, et une page qui explique comment s’en servir.

contenu
Dans l’archive
--------------
  Budget personnel.csv   la base de données
  Budget personnel.md    la page d’accueil et le mode d’emploi
  IMPORTER.txt

Chaque entrée ou sortie d’argent est une ligne. Ajoute une vue « Tableau » groupée par Catégorie, et une somme sur la colonne Montant.

Importer dans Notion
--------------------
1. Dans Notion : Paramètres → Importer → « CSV ».
2. Choisis le fichier .csv de l'archive : il devient une base de données.
3. Importe aussi le fichier .md (Importer → « Text & Markdown ») : c'est la page
   d'accueil, avec le mode d'emploi. Glisse la base dedans.

Le CSV s'ouvre aussi dans Excel et Google Sheets.
