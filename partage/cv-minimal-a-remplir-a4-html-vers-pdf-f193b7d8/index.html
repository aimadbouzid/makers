CV minimal à remplir (A4, HTML vers PDF)

@makers.si 21 novembre 2026 #cv#emploi#modele

Un CV d’une page au format A4, mise en page « minimal ». Tu remplaces le texte d’exemple, puis tu l’enregistres en PDF depuis ton navigateur. Aucun logiciel à acheter. Le texte d’exemple dit, ligne par ligne, quoi écrire.

contenu

  cv.html       le CV à remplir
  LISEZ-MOI.txt

Remplir le CV
--------------
1. Ouvre cv.html avec un éditeur de texte (Bloc-notes, TextEdit en « texte brut », VS Code).
2. Remplace chaque texte d'exemple par le tien. Garde les balises (<h3>, <li>…) autour.
3. Ouvre le fichier dans Chrome ou Edge → Imprimer → « Enregistrer au format PDF »,
   format A4, marges « Aucune » ou « Par défaut », « Graphiques d'arrière-plan » coché.

Un CV d'une page se lit ; deux pages, seulement après dix ans d'expérience.
