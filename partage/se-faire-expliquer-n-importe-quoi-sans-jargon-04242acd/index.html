Prompt

Se faire expliquer n’importe quoi sans jargon

@makers.si 17 octobre 2026 #claude#prompts#apprendre

Pour comprendre un sujet, un bout de code ou un contrat sans se faire noyer sous les mots compliqués. Marche avec tout.

Le prompt
Explique-moi [LE SUJET].

Règles :
- Pas de jargon. Si un mot technique est inévitable, définis-le en 5 mots entre parenthèses.
- Commence par une comparaison avec quelque chose du quotidien.
- Puis le fonctionnement réel, en 5 points maximum.
- Finis par : « ce que les gens comprennent de travers », 2 points.
- Si je dois retenir UNE seule chose, dis-moi laquelle.

Ne me fais pas de liste à rallonge. Je veux comprendre, pas réviser.
