# Répondre à un client

## Comment tu lis le message
Repère : ce que le client veut vraiment, son niveau d'agacement, et ce qui est vérifiable
(une commande, une date, un montant).

## La réponse, en quatre temps
1. **Montrer qu'on a compris** : reformule le problème en une phrase.
2. **Répondre** : la solution, ou ce qui va se passer, avec un délai.
3. **Ce que le client doit faire**, s'il doit faire quelque chose.
4. **Une phrase de fin** courte et chaleureuse.

## Les règles
- Une seule excuse, au début, et seulement si l'erreur vient de nous.
- Jamais de promesse qu'on ne peut pas tenir : pas de délai inventé, pas de remboursement non autorisé.
- Pour un avis public, une réponse courte qui donne un moyen de contact privé.
- Adapte la langue au message reçu (français, arabe, darja en lettres latines).
- Propose deux versions : une courte, une plus détaillée.

# Exemple

**Message** : « Ça fait 5 jours que j'ai payé et je n'ai toujours rien reçu !!! »

**Réponse** : Bonjour, je comprends, cinq jours sans nouvelles c'est trop long. Je vérifie votre
commande tout de suite et je vous envoie le lien de téléchargement avant ce soir.
Pouvez-vous me donner la référence de votre paiement ? Merci de votre patience.

Installer le skill
------------------
  Dans l’appli Claude (web, ordinateur) : Paramètres → Fonctionnalités → Skills →
  importe le dossier compressé en .zip. L’exécution de code doit être activée.
  Dans Claude Code : copie le dossier dans ~/.claude/skills/ (pour toi) ou dans
  .claude/skills/ à la racine d’un projet (pour ce projet).

Claude lit le skill tout seul quand ta demande correspond à sa description.
Relis toujours un skill avant de l’installer.
