Template Notion : Suivi de candidatures

@makers.si 21 novembre 2026 #notion#organisation#planner

Une base « Suivi de candidatures » prête à importer dans Notion (et lisible dans Excel ou Google Sheets) : colonnes Entreprise, Poste, Lien de l’offre, Envoyée le, Statut, Relance le, Notes, quelques lignes d’exemple, et une page qui explique comment s’en servir.

contenu
Dans l’archive
--------------
  Suivi de candidatures.csv   la base de données
  Suivi de candidatures.md    la page d’accueil et le mode d’emploi
  IMPORTER.txt

Une candidature par ligne. Statuts conseillés : À envoyer, Envoyée, Entretien, Refus, Offre. Relance au bout d’une semaine sans réponse.

Importer dans Notion
--------------------
1. Dans Notion : Paramètres → Importer → « CSV ».
2. Choisis le fichier .csv de l'archive : il devient une base de données.
3. Importe aussi le fichier .md (Importer → « Text & Markdown ») : c'est la page
   d'accueil, avec le mode d'emploi. Glisse la base dedans.

Le CSV s'ouvre aussi dans Excel et Google Sheets.
