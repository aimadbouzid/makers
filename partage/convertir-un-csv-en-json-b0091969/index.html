Convertir un CSV en JSON

@makers.si 21 novembre 2026 #python#donnees#csv

Un script Python sans aucune dépendance qui convertit un fichier CSV (séparateur virgule ou point-virgule, détecté tout seul, accents compris) en JSON propre. Utile pour passer un export Excel à un site ou une appli.
