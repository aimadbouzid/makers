Générateur de plan du site (sitemap.xml)

@makers.si 21 novembre 2026 #node#seo#site

Un script Node.js sans dépendance qui parcourt le dossier de ton site statique et écrit le sitemap.xml que Google attend, avec la date de modification de chaque page.

contenu
Dans l’archive
--------------
  plan-du-site.mjs
  LISEZ-MOI.txt

Lancer : node plan-du-site.mjs ./mon-site https://mon-site.com
Puis ajoute la ligne « Sitemap: https://mon-site.com/sitemap.xml » dans robots.txt, et soumets le plan dans Google Search Console.
