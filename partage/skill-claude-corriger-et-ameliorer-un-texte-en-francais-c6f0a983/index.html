# Corriger un texte en français

## Deux étapes
1. **La correction** : orthographe, accords, conjugaison, ponctuation, typographie française
   (espace avant « : ; ! ? », guillemets « »). Rends le texte corrigé, puis la liste des
   fautes importantes avec une explication d'une ligne.
2. **L'amélioration**, seulement si on la demande ou si le texte en a vraiment besoin :
   phrases plus courtes, mots répétés, tournures lourdes.

## Les règles
- Ne change ni le sens, ni le ton, ni le niveau de langue de l'auteur.
- Garde les mots en arabe, en darja ou en anglais tels qu'ils sont, sauf faute évidente.
- Pour un message court (SMS, WhatsApp), corrige sans le rendre solennel.
- Si une phrase est ambiguë, demande plutôt que deviner.

Installer le skill
------------------
  Dans l’appli Claude (web, ordinateur) : Paramètres → Fonctionnalités → Skills →
  importe le dossier compressé en .zip. L’exécution de code doit être activée.
  Dans Claude Code : copie le dossier dans ~/.claude/skills/ (pour toi) ou dans
  .claude/skills/ à la racine d’un projet (pour ce projet).

Claude lit le skill tout seul quand ta demande correspond à sa description.
Relis toujours un skill avant de l’installer.
